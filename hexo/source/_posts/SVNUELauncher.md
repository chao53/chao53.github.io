## Unreal SVN Launcher - 工具说明

**作者：@韩信**

### 1. 项目概述

Unreal SVN Launcher 是一款使用 Python 和 PyQt6 开发的桌面应用程序，旨在为 Unreal Engine 开发者提供一个图形化的 SVN 工作流管理界面。

本工具将SVN的检出、更新、日志查看等命令行操作，与UE项目特有的配置修改（如切换角色、设置启动地图）相结合，最终通过打包成单个可执行文件，为团队提供一个统一、便捷的入口点。

### 2. 功能列表

#### **SVN 集成与远程仓库管理**

- **远程仓库浏览器**:
  - 在UI中以可展开的树形结构展示远程SVN仓库的目录。
  - 自动扫描并识别目录中的UE项目（通过查找 .uproject 文件），并以特殊图标加以区分。
  - 在选中任意远程目录或项目时，可实时预览其最新的提交历史。
- **项目检出 (Checkout)**:
  - 支持从远程浏览器中选择任意项目或文件夹，并将其完整检出到本地。
  - 支持对包含多个UE项目的大型仓库进行**稀疏检出**，即只下载用户选中的单个子项目，节省时间和磁盘空间。

#### **本地工作区管理**

- **本地项目列表**: 集中管理已检出到本地的所有SVN工作副本。
- **版本更新**:
  - 支持将本地项目更新到最新版本。
  - 支持在提交历史中选择任意版本，并将项目回溯或更新到该指定版本。
- **多项目仓库支持**:
  - 能够识别本地工作副本是单一UE项目，还是包含多个UE项目的父仓库。
  - 对于多项目仓库，提供下拉框以选择要操作的具体子项目。

#### **Unreal Engine 深度集成**

- **项目启动**:
  - 自动查找与本地项目关联的UE引擎版本并启动编辑器。
  - 支持在启动前，根据用户选择动态修改项目的INI配置文件。
- **动态角色配置**:
  - 自动扫描项目 Content 目录下的角色资产文件夹。
  - 在UI中生成角色选择列表，启动时可将选中角色信息写入 DefaultGame.ini。
- **自动启动地图设置**:
  - 根据用户选择的角色，自动在 Content/Maps 目录下查找匹配的地图文件（L_<角色名>_Main.umap）。
  - 将找到的地图路径写入 DefaultEngine.ini，作为编辑器的默认启动地图。

#### **核心特性**

- **“一键启动” 工作流**: 将“SVN更新到最新”、“动态修改INI配置”和“启动编辑器”三个步骤合并为一个按钮，实现全自动流程。
- **异步操作与中断**: 所有耗时的SVN操作（检出、更新）均在后台异步执行，保证UI界面流畅不卡顿。同时提供专用的“取消”按钮，可随时中断当前操作。
- **独立部署**: 使用PyInstaller打包成单个 .exe 文件，并内置了完整的SVN命令行工具集，用户无需在本地安装任何SVN环境，解压即可使用。

### 3. 技术实现

- **开发语言**: Python 3
- **GUI**: PyQt6
- **版本控制交互**: 通过 subprocess 模块调用内置的 svn.exe 命令行工具，并解析其标准输出。
- **异步处理**: 使用 QProcess 和信号槽 (Signal & Slot) 机制处理耗时命令，实现UI的实时反馈和非阻塞操作。
- **配置文件处理**: 采用基于正则表达式的文本行级读写，精确修改UE的 .ini 文件，以保留原有的格式和注释。
- **打包与分发**: PyInstaller
