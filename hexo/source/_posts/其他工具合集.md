- ### **UE5 自动化角色展示工具**

  #### **1. 项目概述 (Project Overview)**

  本项目是一个基于 Unreal Engine 5 的自动化工具，旨在**一键式为3D角色模型生成高质量的转盘展示视频**。它解决了美术师和灯光师在评审模型和光照效果时，需要手动设置场景、动画和渲染的繁琐流程。通过脚本化和流程自动化，该工具能确保每次输出的视频都遵循统一的标准，极大地提升了团队的协作效率和资产的展示质量。

  **目标用户**：角色美术师、灯光师、技术美术师、项目管理人员。

  **核心价值**：效率提升、标准化、易用性。

  #### **2. 核心功能 (Core Features)**

  - **一键式操作**：用户只需在编辑器中选择目标角色，或通过命令行指定，即可启动完整的视频生成流程。

  - **动态场景生成**：自动在当前关卡中生成一个专用的拍摄用摄像机，并将其绑定到目标角色上，无需手动创建和摆放。

  - - **程序化动画**：通过代码动态创建 Level Sequence，并生成一段精心设计的转盘动画：

    - **摄像机环绕**：摄像机首先围绕静止的角色旋转360度，全方位展示模型在静态光照下的细节。
    - **角色自转**：随后，角色自身旋转360度，用于展示模型在动态光照下的材质和阴影变化。

  - **高质量渲染**：集成 **Movie Render Queue (MRQ)**，利用可配置的渲染预设（Presets）进行离线高质量渲染，支持输出EXR、PNG等高动态范围图像序列。

  - **自动化后期处理**：渲染完成后，工具会自动调用 **FFmpeg** 库将渲染出的图像序列合成为视频文件（如 .mp4），并支持多种编码选项（如无损或指定码率）。

  - **智能资源清理**：在整个流程结束后，工具会自动清理场景中生成的临时摄像机和渲染出的图像序列，保持项目整洁。

  - **高度可配置**：几乎所有关键参数都可以通过命令行进行配置，包括：

    - 渲染质量预设 (MRQ Preset)
    - 摄像机距离与高度
    - 视频总时长
    - 视频编码质量（无损/码率）

  #### **3. 技术实现细节 **

  本工具主要由 Python 脚本构成，深度利用了 Unreal Engine 的 Python API，并结合了外部工具，形成一个完整的自动化管线。

  - **前端交互与参数解析**：
    - 使用 Python 的 argparse 模块来解析命令行参数，为工具提供了灵活的配置接口。这使得工具既可以由用户手动执行，也能够轻松地集成到CI/CD系统（如Jenkins）中。
  - **场景与序列创建 (SequenceCreator)**：
    - **UE Python API**: 调用 unreal.EditorActorSubsystem 在场景中动态生成和销毁Actor（如拍摄用的 BP_ShotCamera）。
    - **资产自动化**: 利用 unreal.AssetToolsHelpers 和 unreal.LevelSequenceFactoryNew 在内容浏览器中自动创建 Level Sequence 资产。
    - **程序化Sequencer**: 通过操作 unreal.LevelSequence 对象，动态添加Possessable绑定、Transform轨道、Attach轨道和Camera Cut轨道。关键帧数据（如旋转角度和时间）是根据输入参数实时计算并写入轨道的，实现了完全的程序化动画。
  - **渲染管线 (Renderer)**：
    - **Movie Render Queue (MRQ) 集成**: 通过 unreal.MoviePipelineQueueSubsystem 与MRQ深度集成。脚本动态创建渲染队列、添加渲染作业，并将程序化生成的 Level Sequence 和用户指定的**渲染预设 (Preset)** 关联起来。
    - **异步回调机制**: 巧妙地利用了MRQ的 OnMoviePipelineExecutorFinished 和 OnExecutorErrored 回调事件。这使得渲染完成后的视频合成和资源清理等后续步骤可以**异步触发**，整个流程无需人工干预。
  - **视频编码 (VideoEncoder)**：
    - **外部进程调用**: 使用 Python 的 subprocess 模块调用强大的开源视频处理库 **FFmpeg**。工具内置了FFmpeg，无需用户额外安装。
    - **智能图像检测**: 能够自动检测渲染输出文件夹中的图像格式（EXR或PNG）和文件命名序列（如 FileName.####.exr）。
    - **灵活编码**: 根据用户参数选择不同的FFmpeg命令行参数，实现高质量无损编码（-crf 0）或指定码率的压缩编码（-b:v），以适应不同需求（如内部评审或最终展示）。

  #### **4. 工作流程**

  *(这里建议你自己画一个简单的工作流程图，能极大地增强作品集的效果。上图是一个示例)*

  1. **启动 (Initiation)**：用户在编辑器中选中一个Actor，然后通过自定义的UI按钮或命令行执行Python脚本，并传入配置参数（如MRQ预设路径）。
  2. **序列生成 (Sequence Generation)**：脚本自动创建一个新的 Level Sequence 资产，并在场景中生成一个摄像机。
  3. **动画绑定 (Animation & Binding)**：脚本将摄像机和选中的Actor绑定到 Level Sequence 中，并程序化地为它们的Transform轨道添加关键帧，创建转盘动画。摄像机被附加（Attach）在角色上，以实现完美的环绕运镜。
  4. **渲染 (Rendering)**：脚本将配置好的渲染任务提交给Movie Render Queue，后者启动一个独立的PIE窗口进行高质量离线渲染，输出图像序列。
  5. **编码与合成 (Encoding & Composition)**：MRQ渲染成功后，其完成回调事件被触发。脚本调用FFmpeg，将输出的图像序列合成为 .mp4 视频。
  6. **清理 (Cleanup)**：视频生成后，脚本删除场景中的临时摄像机和磁盘上的临时图像文件。
  7. **完成 (Completion)**：自动打开视频所在的文件夹，用户可立即查看最终成品。

  #### **5. 项目价值与延展性 **

  - **提升效率**：将原本需要数十分钟甚至更久的手动操作缩短为一次点击，极大解放了美术师的生产力。
  - **保证一致性**：标准化的运镜和渲染设置确保了项目中所有角色的展示视频风格统一，便于横向比较和评审。
  - **降低技术门槛**：美术师无需深入了解Sequencer或MRQ的复杂设置，即可获得专业级的渲染输出。
  - **高度可扩展**：该工具的模块化设计（SequenceCreator, Renderer, VideoEncoder）使其易于扩展。未来可以轻松添加更多功能，例如：
    - 支持多角度固定机位拍摄。
    - 自动切换不同的光照场景 (Level Variant)。
    - 集成UI界面，提供更友好的用户交互。
    - 将视频自动上传到指定的内部评审服务器。
