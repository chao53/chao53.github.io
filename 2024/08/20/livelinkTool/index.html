项目概述 (Project Overview)

本项目是一款桌面应用程序，用于处理来自面部捕捉应用（如Apple Live Link Face）的实时数据。该工具的核心功能是接收数据流，并提供录制、保存、重放和远程传输的能力。

为了适应不同的工作环境，工具内置了两种操作模式：“局-域网录制”用于本地网络环境，“服务器录制”则通过连接一台云服务器，允许从外网接收数据，支持多通道并行录制。此外，工具还包含一个数据播放器，可以对录制好的文件进行预览、控制和剪辑。

核心功能与用途 (Core Functions & Applications)

  1. 数据录制与保存：
    • 用途：备份演员的面部表演数据，或捕捉特定表情以供后续使用。
    • 功能：可以录制指定时长的面部数据流，并将其保存为本地 .dat 文件，方便归档和管理。
  2. 远程数据传输：
    • 用途：解决手机和电脑不在同一局域网内而无法连接的问题，支持远程工作和分布式团队协作。
    • 功能：通过“服务器录制”模式，用户可以配置一台云服务器作为中继。手机只需连接互联网，即可将数据发送到服务器，再由服务器转发至本地电脑进行录制。
  3. 多通道并行录制：
    • 用途：在需要同时捕捉多名演员表情的场景下（如多人对话动画），提高录制效率。
    • 功能：“服务器录制”界面提供了一个通道管理列表，用户可以添加多个录制通道，为每个通道设置独立的接收端口和保存文件，并对它们进行独立或批量的开始/停止控制。
  4. 数据重放与剪辑：
    • 用途：方便动画师在没有演员实时配合的情况下，反复预览、调试和使用已录制的表演数据。
    • 功能：内置的数据播放器可以加载 .dat 文件，并提供以下控制：
      • 进度条拖动，实现快速跳转。
      • 播放、暂停、逐帧前进/后退。
      • 循环播放和自定义区间播放。
      • 将选定的区间“另存为”一个新的、独立的片段文件。

技术实现 (Technical Implementation)

  • 应用程序框架：使用 Python 作为主要开发语言，图形用户界面（GUI）基于 PyQt6 框架构建。
  • 数据处理：通过Python的 socket 模块接收UDP数据包。录制的数据（包含时间戳和原始数据）使用 pickle 模块进行序列化后存入文件。
  • 并发处理：为了避免录制、重放等长时间操作阻塞GUI，所有耗时任务都在独立的 QThread 后台线程中执行。多通道录制会为每个通道创建独立的线程，实现并行处理。
  • 远程连接方案：
    • 核心组件：使用开源反向代理工具 frp，并需要用户提供一台具有公网IP的云服务器（如阿里云ECS）部署frps服务端。
    • 集成方式：本工具在图形界面中集成了frp的客户端(frpc)。当用户点击连接时，程序会根据界面上的配置动态生成frpc.toml文件，并通过subprocess模块在后台启动frpc.exe进程，建立与云服务器的连接隧道。
    • 状态反馈：程序通过实时解析frpc客户端的日志，来判断每个通道的连接状态（成功或失败），并在UI表格中通过颜色变化（绿色/红色）向用户提供反馈。
  • 打包与部署：项目代码结构支持使用 PyInstaller 进行打包。通过–add-data参数将frpc.exe等外部依赖捆绑，生成一个单文件的.exe可执行程序，方便在Windows环境下分发和使用。
